# Libre AI Public Vote Comparison

Comparer les positions que vous choisissez d’exprimer à des votes publics sourcés. Ce produit vise les personnes qui souhaitent comparer leur position à des décisions publiques précises, avec leurs sources.


## Usages visés

- Examiner une décision publique, son vote et sa source.
- Comparer cet enregistrement à une réponse fournie volontairement.
- Voir les informations manquantes et distinguer vote, abstention et absence lorsque la source le permet.

Il s’agit de comparer des votes, sans conseil de vote ni étiquetage politique.

**Aujourd’hui :** ce dépôt présente le projet sous forme de documentation ; aucune application n’est encore disponible.
