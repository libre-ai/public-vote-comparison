# Libre AI Public Vote Comparison

Compare positions you choose to state with sourced public voting records. This proposed product is for people examining public decisions who want to understand where their stated position agrees or differs.


## Intended uses

- Look at a specific public decision alongside its recorded vote and source.
- Compare that record with an answer you deliberately provide.
- See missing information and distinguish a vote, an abstention and an absence when the source does.

The aim is to compare votes, without voting recommendations or political labels.

**Today:** source code and tests are present; local integration is underway. See the [development guide](docs/DEVELOPMENT.md) for setup and verification status.
